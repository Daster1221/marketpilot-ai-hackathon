# MarketPilot AI — прототип для хакатона

Локальный помощник SMM: бриф бизнеса → три темы и текста → правки → согласование → публикация в Telegram.

**Основной интерфейс теперь в Telegram-боте:** анкета, профиль бизнеса, генерация, правки, согласование и отправка. Запуск через `start_bot.bat`. Настройка и ограничения описаны в [TELEGRAM.md](TELEGRAM.md). Веб-версия ниже — отдельный ранний прототип.

Голос распознаётся локально через faster-whisper; на новом компьютере подготовьте его через `install_speech.bat`. История версий хранится локально. AI-правки получают текущий текст и временную сводку требований до 800 символов, без полной истории; после принятия или отмены сводка очищается. Генерация и AI-правки поддерживают Telegram HTML: жирный, курсив и цитаты.

## Запуск

Нужен Python 3.11 или новее. В папке проекта выполните:

```powershell
python app.py
```

Откройте http://127.0.0.1:8000. Без ключей работает демонстрация на шаблонах; это не генерация AI.

Для DeepSeek скопируйте `.env.example` в `.env`, заполните `DEEPSEEK_API_KEY` и перезапустите приложение. `DEEPSEEK_MODEL` задаётся отдельно. Доступность модели и условия API нужно проверить перед покупкой: платный вызов в этом прототипе ещё не проверен.

Для реальной публикации заполните `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHANNEL_ID`, добавьте бота администратором своего тестового канала с правом публикации. После согласования нажмите «Опубликовать в Telegram». Это реальная отправка в заданный канал. При неопределённом результате проверьте канал вручную: повтор автоматически не производится.

Тексты и статусы хранятся в `data/marketpilot.db`. Ключи не добавляйте в Git. Сервер доступен только на локальном компьютере. Когда подключён DeepSeek, бриф уходит внешнему провайдеру — используйте публичные или специально подготовленные данные.

## Что реализовано

- Сохранение брифа и постов в SQLite.
- Подключение DeepSeek; явный деморежим без ключа.
- Три темы, тексты и описания будущих изображений.
- Редактирование, согласование, сброс согласования после правок.
- Защита от публикации несогласованного текста и повторной отправки опубликованного поста.
- Отправка текста в один Telegram-канал через бота.
- Счётчики состояний постов.

## Что ещё предстоит

Управление из Telegram, загрузка документов и чтение сайта, генерация изображений, планировщик, VK/MAX, получение метрик и содержательные отчёты. Описания изображений не являются сгенерированными картинками; счётчики статусов не являются маркетинговой аналитикой. Текущий интерфейс согласования — локальная страница.

Проверки: `python -m unittest -v`. Они проверяют переходы согласования, запрет отправки без согласования и блокировку дублей; внешние API подменяются тестовыми ответами.
