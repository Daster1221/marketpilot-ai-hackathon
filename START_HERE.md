# Запуск бота с анкетой на Windows

**Текущее подключение — ProxyAPI.** Ключ в `.env` уже принят ProxyAPI. Ранее 401 возникал потому, что этот ключ отправлялся напрямую в DeepSeek. Сейчас установлены `DEEPSEEK_BASE_URL=https://api.proxyapi.ru/v1` и `DEEPSEEK_MODEL=deepseek/deepseek-v4.1-flash`. Название переменной `DEEPSEEK_API_KEY` оставлено для совместимости; в ней хранится ключ ProxyAPI. Новый ключ создавать не нужно.

Рабочая папка: `C:\Users\Artur\Desktop\MarketPilot AI`.

Запускайте `start_bot.bat` из этой папки. Вложенный `content-zavod` — другой проект с другими настройками; для этого бота он не нужен. Веб-сервер и браузер для работы бота не требуются.

## 1. Подготовьте Python

Нужен Python 3.11+. В PowerShell команда `python --version` должна показывать версию. Установите Python с включённой опцией Add Python to PATH, если команда не находится. Для сборки обложек с текстом установите `python -m pip install -r requirements-images.txt`. На текущем компьютере библиотека уже доступна.

## 2. Заполните настройки

Откройте `.env` в этой рабочей папке через Блокнот. Если файла нет, первый запуск `start_bot.bat` создаст его из `.env.example` и откроет редактор. В проводнике включите показ расширений: имя должно быть `.env`, а не `.env.txt`.

Пример структуры (замените пояснения после `=` своими значениями):

```dotenv
TELEGRAM_BOT_TOKEN=токен_своего_бота_из_BotFather
TELEGRAM_OWNER_ID=свой_числовой_Telegram_ID
TELEGRAM_CHANNEL_ID=@имя_своего_тестового_канала
DEEPSEEK_API_KEY=свой_API_ключ_ProxyAPI
DEEPSEEK_BASE_URL=https://api.proxyapi.ru/v1
DEEPSEEK_MODEL=deepseek/deepseek-v4.1-flash
```

Ключ ProxyAPI берётся в кабинете ProxyAPI; он не является токеном Telegram или паролем от чата. Убедитесь, что баланс ProxyAPI пополнен. Токен бота получите в Telegram у @BotFather через `/newbot`. Не вставляйте ключи в Python-код.

Бот доступен только пользователям из `TELEGRAM_OWNER_ID`. Для одного владельца задайте `TELEGRAM_OWNER_ID=8460400176`. Пустое поле запрещает доступ всем. После изменения настроек остановите бота через Ctrl+C и снова запустите `start_bot.bat`.

Канал можно оставить пустым до проверки генерации. Перед публикацией добавьте бота администратором вашего тестового канала с правом отправки сообщений и заполните `TELEGRAM_CHANNEL_ID`. Для публичного канала подойдёт `@username`, для приватного нужен настоящий числовой ID канала. ID пользователя и ID канала — разные значения.

## 3. Проверьте ключи

Откройте `check_setup.bat`. Он проверит токен Telegram и список моделей DeepSeek без отправки сообщений и генерации контента. Ключи на экран не выводятся.

- `401` — провайдер не принял ключ: прежде всего проверьте соответствие адреса и ключа. Ключ ProxyAPI не работает напрямую на api.deepseek.com.
- `402` при генерации — недостаточно денег на API-балансе.
- Модель отсутствует — укажите ID из списка, который вернёт проверка.
- Нет соединения — проверьте доступ компьютера к `api.telegram.org` и `api.proxyapi.ru`.

Даже успешная проверка списка моделей не гарантирует наличие баланса и успешный запрос генерации.

## 4. Запустите

Закройте старое окно бота через Ctrl+C. Откройте `start_bot.bat` двойным щелчком и оставьте окно открытым. Запускайте один экземпляр с одним токеном. После каждого изменения `.env` нужен перезапуск.

Альтернатива в PowerShell:

```powershell
cd 'C:\Users\Artur\Desktop\MarketPilot AI'
python -u telegram_bot.py
```

## 5. Проверьте сценарий в Telegram

1. Откройте именно того бота, чей токен записали в `.env`.
2. Отправьте `/start` и заполните пять вопросов. Подтвердите профиль кнопкой «Всё верно». Старая завершённая анкета переносится автоматически.

   Бот обновляет одно рабочее сообщение. Ответы после обработки убираются из ленты; длинные тексты листаются внутри этого же экрана.
3. Нажмите «Новый пост» или опишите инфоповод. Без количества бот готовит один черновик по правилам САЛАВАТСТЕКЛО; от двух до пяти — только по прямому запросу. Эмодзи в постах запрещены, пометки для проверки редактором показаны отдельно от публикуемого текста.
4. Можно отправить голосовое до трёх минут и 5 МБ. Оно распознаётся на нашем компьютере через faster-whisper, без отправки аудио в ProxyAPI. На новом компьютере запустите `install_speech.bat` один раз. На текущем компьютере модель уже доступна. Сначала бот покажет расшифровку — подтвердите или исправьте её.
5. Нажмите «Изменить» под конкретным постом и напишите пожелание, например «Сократи и убери официоз». Следующие правки можно писать подряд: история и контекст сохраняются для этого поста. В конце нажмите «Готово, закончить правки». Для ручной замены выберите «Заменить текст целиком».
6. Нажмите «Отправить», проверьте название канала и текст, затем «Подтвердить отправку». Это реальная публикация.
7. «Отменить» убирает пост из работы; «Восстановить» возвращает его в черновики. «Не менять» отменяет только режим редактирования.

Без DeepSeek-ключа бот честно показывает шаблонный деморежим. С неверным ключом он показывает ошибку, а не подменяет генерацию шаблоном.

## Что исправлено при проверке

- `.env` теперь имеет приоритет над старыми переменными Windows. Поддерживаются значения в кавычках и UTF-8 BOM.
- Ошибки DeepSeek 401/402/429, тайм-ауты и неправильная структура ответа объясняются отдельно.
- Тайм-аут генерации увеличен до 120 секунд; тайм-аут Telegram остаётся отдельным.
- Стартовые ошибки Telegram выводятся без адреса, содержащего токен. При конфликте второго экземпляра бот прекращает опрос.
- Добавлены шаблон настроек и отдельная проверка подключений.

Ранее прямой DeepSeek вернул 401 для ключа ProxyAPI. После настройки правильного адреса ProxyAPI ключ принят. Адрес и модель задаются через `.env`, проверка и бот используют одно подключение. Официальная документация: https://proxyapi.ru/docs.

Изображения, чтение сайта, документы и расписание в этом простом боте ещё не реализованы. Ссылка на сайт пока входит только в бриф. У каждого пользователя своя сохранённая очередь; два разрешённых пользователя обрабатываются независимо. Задания одного пользователя выполняются по очереди: не отправляйте одну задачу несколько раз во время генерации.


## Документы и маркетолог

На новом компьютере выполните `python -m pip install -r requirements-documents.txt` или запустите `install_documents.bat`.

В боте откройте «Документы» и пришлите файл. В Mini App раздел «Маркетолог и документы» доступен на главной и в профиле. Поддерживаются PDF с текстовым слоем, DOCX, TXT, MD до 5 МБ и 60 000 символов; PDF до 80 страниц. OCR сканов пока нет.

Документы хранятся локально в SQLite, для выжимки текст отправляется вашему AI-провайдеру. Повторный разбор одинакового текста для одного пользователя не оплачивается. Можно удалить документ из знаний. Сброс компании удаляет её документы и память маркетолога, посты сохраняются.

«Маркетолог» учитывает профиль, документы, 15 последних тем/статусов публикаций и текущий контент-план. Полный текст поста подгружается только по явно указанному номеру (до двух за запрос). Например: «Сравни пост №40 и пост №41», «Составь контент-план на неделю по нашим материалам». Память диалога — компактная сводка до 1000 символов; полная история сообщений не отправляется модели. Планы маркетолога — предложения, не согласованные публикации. Они общие для бота и Mini App; из темы можно создать черновик.

Редактирование отдельного поста сохраняет прежнюю изолированную память правок. Полные файлы, весь архив публикаций и историю правок в каждый запрос не пересылаем. Проверка: `python -m unittest discover -q`.


## Доступ пользователей

В Mini App откройте «Профиль → Настройки → Пользователи и доступ». Владелец может добавить человека по числовому Telegram ID и отозвать доступ у приглашённых. Ники и имена берутся из Telegram после первого входа; если бот уже знает пользователя, имя подставляется сразу. Перезапуск при добавлении не нужен. Данные и доступ сохраняются локально в SQLite.

Администратором управления доступом по умолчанию является первый ID из TELEGRAM_OWNER_ID. Для явного списка администраторов можно задать TELEGRAM_ADMIN_ID (ID через запятую). Новые пользователи права администратора не получают. Постоянные ID из TELEGRAM_OWNER_ID защищены от удаления через интерфейс. Общий лимит AI и настроенная площадка публикации используются как прежде; это доступ к текущему экземпляру бота, не полноценная модель организаций и ролей.

Кнопка открытия Mini App внутри сообщения главного меню убрана. Запуск через стандартную кнопку приложения рядом со строкой ввода Telegram сохранён.


При создании поста из темы контент-плана сведения передаются автоматически: отдельные факты темы и краткий контекст обсуждения. Уточнения маркетологу обновляют сохранённый план без смены ссылки темы. Для старых планов используется сохранённая краткая память. Повторно спрашиваются только недостающие критические сведения; догадки о датах и местах не добавляются. В Mini App кнопка темы сразу открывает подготовку с этими данными, а индикатор обработки находится внутри кнопки.


## ВК: отправка текста

Нужны локальные VK_ACCESS_TOKEN и VK_GROUP_ID. В карточке поста бота выберите «ВК · только текст», проверьте текст и подтвердите. В Mini App такой же блок есть при просмотре и редактировании поста. Изображение не передаётся; форматирование и спойлеры становятся видимым обычным текстом. Telegram-публикация не меняется. После отправки доступна ссылка на запись. При неопределённой доставке повтора нет: проверьте стену вручную. Автоматический кросспостинг и расписание VK в этот сценарий не входят.
