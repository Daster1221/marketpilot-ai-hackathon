# Сравнение редакционной и авторской инструкции

Два вымышленных задания на GPT-4.1. Это реальные ответы модели, а не отредактированные вручную эталоны. Примеры не публиковались и не являются фактами о компании. Оцениваем связность и развитие темы, а не количество приёмов оформления.


## Матч

Исходные данные: Подготовь один анонс для коллег. 20 ноября в 18:00 на площадке спорткомплекса «Старт» состоится футбольный матч: команда первого цеха играет со вторым цехом. Зрители могут поддержать коллег, участие зрителей бесплатное. После матча в 19:30 организаторы собирают предложения по следующему турниру в этом же спорткомплексе. Кубок, призы и фавориты не объявлены. Не придумывай их.

### Предыдущая инструкция

```html
<b>⚽ Первый цех против второго: выбирайте, за кого болеть!</b>

На площадке спорткомплекса «Старт» сразятся команды первого и второго цеха. Можно прийти поддержать своих коллег: для зрителей вход бесплатный.

<blockquote><b>20 ноября · спорткомплекс «Старт»</b>
18:00: матч первого и второго цеха
19:30: обсуждение предложений по следующим турнирам с организаторами в том же месте
Вход для зрителей свободный</blockquote>

Есть свои идеи для будущих корпоративных игр? После матча можно обсудить их с организаторами и повлиять на программу следующих встреч.

#Вкоманде
```


### Новая инструкция

```html
<b>⚽ Футбольный вечер для коллег: первый и второй цех выходят на поле</b>

На этот раз встречаемся не у станков, а на футбольном поле - здесь все роли меняются. <b>20 ноября в 18:00</b> в спорткомплексе «Старт» команда первого цеха сыграет против коллег из второго. Можно прийти поддержать своих, посмотреть игру и просто пообщаться вне привычной обстановки. Для зрителей вход свободный.

А после матча, <b>в 19:30</b> в том же спорткомплексе, организаторы собирают предложения по следующему турниру. Есть идеи для будущих игр? Захотите предложить новый формат - присоединяйтесь к обсуждению.

Давайте встретимся на трибунах - поддержим коллег на поле и вместе подумаем, чем удивить друг друга в следующий раз.

#Вкоманде
```


## Клуб

Исходные данные: Напиши один пост для коллег: открываем киберклуб для сотрудников. Первая онлайн-встреча 21 ноября в 19:00, знакомимся и собираем предложения по игровым дисциплинам. Опыт не требуется, могут прийти новички. Для участия надо написать организатору в корпоративном чате. Призы, турнир и победители пока не заявлены. Имена и ссылки не даны.

### Предыдущая инструкция

```html
<b>🎮 Хочешь найти коллег для совместных игр?</b>

Запускаем киберклуб для всех сотрудников. Новички и те, кто никогда не участвовал, тоже в команде - опыт не требуется!

Первая встреча пройдет онлайн: познакомимся и обсудим, в какие игры будем играть. Это шанс сказать своё слово и повлиять на будущие мероприятия клуба.

<blockquote><b>21 ноября, 19:00 · онлайн</b>
Программа встречи: знакомство и сбор ваших предложений по игровым дисциплинам.

Чтобы присоединиться, напишите организатору в корпоративном чате.</blockquote>

#Вкоманде
```


### Новая инструкция

```html
<b>🎮 Открываем киберклуб для сотрудников</b>

У многих из нас игры - это не только способ расслабиться, но и отличный повод познакомиться ближе. Теперь у коллег появится собственное место для общения по интересам вне рабочих задач.

Приглашаем на первую онлайн-встречу киберклуба <b>21 ноября в 19:00</b>. В этот вечер мы познакомимся, обсудим любимые жанры, соберём предложения по игровым дисциплинам и поймём, во что хочется сыграть вместе.

Опыта в киберспорте не требуется: достаточно интереса попробовать. Если уже давно хотели найти напарника по игре или просто посмотреть, как всё устроено, - это отличный повод начать.

Чтобы присоединиться, напишите организатору в корпоративном чате. Давайте соберёмся компанией и сделаем свои вечера ярче!

#Вкоманде
```


## Что показывает прогон

Новая версия разворачивает социальный смысл клуба и связывает матч с последующим обсуждением. При этом модель способна ошибаться: в примере матча добавлены трибуны, которых не было в исходнике. Это не эталон достоверности и не оценка 10/10. Авторская свобода не отменяет редакторского согласования проверяемых обстоятельств.
