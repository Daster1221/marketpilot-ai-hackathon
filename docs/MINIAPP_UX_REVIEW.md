# Проверка мини-аппа: 15 ноября

Проверено: главная, переход в маркетолога, документы, форма задачи, мобильная ширина 390 px.

| Проблема | Изменение |
|---|---|
| Ответ Claude с пояснением и fenced JSON отклонялся целиком | Принимается один законченный JSON-объект внутри блока кода; частичные и неоднозначные ответы не исправляются догадками. Повторного платного запроса нет. |
| В маркетологе активна «Главная» | Отдельный переход «Маркетолог» в нижней навигации с правильным активным состоянием. Создание поста остаётся отдельным процессом. |
| Форма визуально упирается в нижнюю панель | Дополнительный нижний отступ. На ширине телефона при фокусе поля панель скрывается. |
| Ошибка далеко от действия и непонятно, что повторять | Сообщение внутри формы, введённый текст сохраняется в сессии браузера, кнопка «Попробовать снова». |
| Неочевидно, что написать | Короткое вступление, быстрые действия «План на неделю» и «Новый пост». |
| «Знания компании · 0 документов» выглядят технически | Краткое название «Документы компании», подробности загрузки внутри раскрываемого блока. |
| Восстановление задачи открывало не тот экран | Задачи маркетолога и документов восстанавливаются в маркетологе. |

Форма проверена на мобильной ширине: нижняя граница 736 px, начало панели 770 px (без клавиатуры). Это проверка браузерного макета, а не обещание одинакового поведения всех версий iOS/Android Telegram.

Дальнейшие улучшения: поиск по длинной истории маркетолога; постраничный список документов; отдельные карточки подключения реальных площадок вместо пустого раздела; подстановка текущего названия компании во всех старых демонстрационных экранах. Не выдавать счётчики материалов за маркетинговые метрики.

Бот: выбранная текстовая модель показана на главной. При генерации изображения используется проверенный анимированный фирменный Premium-эмодзи; нейтральные подписи меняются локально каждые 3 секунды. Нет процентов, обещаний проверки фактов или новых AI-запросов ради анимации.
